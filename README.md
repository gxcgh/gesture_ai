# Gesture Recognition with ESP32 and TinyML

An end-to-end beginner-friendly project that teaches you how to connect an MPU6050 sensor to an ESP32 DevKit V1, collect motion data using Python, train a machine learning model with `scikit-learn`, convert it using `emlearn`, and run real-time edge AI inference directly on the microcontroller.

---

## 🛠️ System Requirements & Prerequisites

### 1. Hardware Requirements
* **ESP32 DevKit V1** microcontroller board
* **MPU6050** 6-Axis Accelerometer & Gyroscope breakout module
* **Breadboard** and male-to-female / male-to-male jumper wires
* **USB Cable** to connect the ESP32 to your computer

### 2. Software & Tooling Requirements
* **Arduino IDE** (version 2.x recommended) installed on your computer.
* **Python 3.x** installed with pip.

### 3. Required Python Libraries
Run the following command in your terminal or command prompt to install all necessary Python dependencies:
```bash
pip install pyserial pandas scikit-learn emlearn
```

---

## 🔌 Hardware Wiring Guide

Connect the MPU6050 to your ESP32 DevKit V1 using the I2C communication protocol:

| MPU6050 Pin | ESP32 DevKit V1 Pin | Description |
| :--- | :--- | :--- |
| **VCC** | **3.3V** | Power supply (Connect to 3.3V, not 5V) |
| **GND** | **GND** | Ground connection |
| **SDA** | **GPIO 21 (D21)** | I2C Data line |
| **SCL** | **GPIO 22 (D22)** | I2C Clock line |

## 📂 Project Structure & Workflow

```text
gesture_recognition_project/
├── 1_data_streamer.ino        # ESP32 sketch for streaming raw CSV sensor data
├── collect_data.py            # Python script to capture serial stream and save CSV
├── train_model.py             # Python script to train ML model and export .h file
├── gesture_model.h            # Compiled C header file generated by emlearn
└── 2_gesture_inference.ino    # ESP32 sketch for running real-time AI predictions
```

---

## 🚀 Step-by-Step Execution Guide

### Step 1: Stream and Collect Data
1. Upload `1_data_streamer.ino` to your ESP32 via Arduino IDE.
2. Run the Python data collection script:
   ```bash
   python collect_data.py
   ```
3. Follow the prompt to enter your target labels (`front`, `back`, `left`, `right`) and record sufficient sample data into `gesture_dataset.csv`.

### Step 2: Train the Model & Export to C
1. Ensure your generated `gesture_dataset.csv` is in the same folder as the training script.
2. Run the training script:
   ```bash
   python train_model.py
   ```
3. This will train a Random Forest model, evaluate its accuracy, and generate the `gesture_model.h` file.

### Step 3: Run Real-Time Inference on ESP32
1. Place the generated `gesture_model.h` file into your Arduino sketch folder.
2. Upload `2_gesture_inference.ino` to your ESP32.
3. Open the **Arduino Serial Monitor** at `115200` baud to watch live gesture predictions update as you tilt and move your device!
